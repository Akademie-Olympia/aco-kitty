# Configuration Reference

`~/.config/kitty/kitty.conf` holds behaviour only. Font, colours and opacity are included from
`~/.config/aco/theme/kitty/theme.conf`, generated by [aco-theme](https://github.com/Akademie-Olympia/aco-theme)
from `aco-theme/theme.conf.tpl`.

---

## Theme

```conf
include ${HOME}/.config/aco/theme/kitty/theme.conf
```

- Font `JetBrainsMonoNL Nerd Font` 10.5, 16 terminal colours, selection, cursor and tab colours follow
  `aco-theme mode|accent|transparency`; running windows reload on SIGUSR1.
- `background_opacity` is `term_opacity` (0.94) with transparency on, 1 with it off.
- The include uses `${HOME}` because kitty resolves `..` through the symlinked config directory.

## Typography

```conf
disable_ligatures always
bold_font        auto
italic_font      auto
bold_italic_font auto
```

- The NL font has no ligatures and `disable_ligatures always` keeps it that way, so `==`, `->` and `!=` stay separate characters.

## Window and behaviour

```conf
shell                      /usr/bin/zsh
window_padding_width       10
confirm_os_window_close    0
enable_audio_bell          no
cursor_shape               beam
cursor_blink_interval      0
url_style                  straight
dynamic_background_opacity yes
hide_window_decorations    yes
```

## Tab bar

```conf
tab_bar_edge          top
tab_bar_style         separator
tab_separator         ""
tab_title_template    "  {title}  "
tab_bar_margin_height 4 0
```

Quiet tabs at the top; the active tab is a slightly raised surface.

## Customising locally

Behaviour: edit `~/.config/kitty/kitty.conf` and reload with <kbd>Ctrl+Shift+F5</kbd>.
Colours or fonts: put tokens into `~/.config/aco/theme.local.conf` (for example `mono_size = 12`) and run `aco-theme apply`.
